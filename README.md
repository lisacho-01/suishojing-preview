# Oria Stone Preview

Static homepage prototypes for **Oria Stone**, a Japanese-language e-commerce concept for natural-stone accessories. The homepage is built around a short "AI diagnosis": visitors answer three questions (theme, colour, and how to receive a coupon), see a recommended stone, and receive an opening gift.

Live preview: https://lisacho-01.github.io/suishojing-preview/

## Pages

- `index.html`: "Quiet Ritual Diagnosis" homepage with the three-question diagnosis and result preview, theme entry points, featured items, and the order flow (made-to-order selection, inspection in Japan, 3–5 week shipping).
- `directions.html`: three homepage design directions side by side (Quiet Ritual, Editorial, AI Diagnosis).
- `oria/`: later ORIA brand prototypes, including a motion homepage, a first-screen draft, and three layout variants (Diagnosis Studio, Talisman Entry, Quiet Catalogue).
- `assets/`: brand name and logo visual tests, and an AI-generated UI visual.

## Stack

Plain HTML, CSS and vanilla JavaScript, with no build step. Hosted on GitHub Pages. Some product photos are loaded from Unsplash.

## Status

Design prototype only. There is no real checkout, and the diagnosis result is a front-end preview.
